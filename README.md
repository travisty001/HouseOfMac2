# HouseOfMac2

Specimen studio for local GLB meshes, Gaussian splats and point clouds. Replaces the retired specimen-gallery viewer.

Live: https://travisty001.github.io/HouseOfMac2/

## Development

Run `npm ci`, `npm test`, and `npm run dev`.

## Publication

Run `npm run build`. Publish the contents of `dist/` (including `.nojekyll`) to the `gh-pages` branch. GitHub Pages serves that branch's root. The Vite base path is `/HouseOfMac2/`.

The previous viewer's history remains in the archived `travisty001/specimen-gallery` repository, with Pages disabled.
